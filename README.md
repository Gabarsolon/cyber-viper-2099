## ⚡ Features

- **Silky Serpentine Movement**: Sub-frame coordinate interpolation and organic sinusoidal spine wave physics.
- **Dynamic Cyber Viper Head**: Expressive glowing eyes with pupil dilation when near food, realistic blinking, and a flickering tongue.
- **Procedural Web Audio Engine**: Zero external audio assets—all sound effects (crystal pentatonic combo chimes, 808 sub-bass drops, fanfare chords) and ambient synthwave background music are synthesized live via the Web Audio API.
- **Overdrive Turbo Boost (`SPACE` / `SHIFT`)**: Drains energy gauge to double your velocity, emits rocket plasma particle exhaust from your tail, casts speed streaks, and awards 2x score.
- **Multi-Tiered Food**:
  - *Pulse Orbs*: Standard glowing cores with rotating orbital rings.
  - *Nova Stars*: Timed golden bonus fruit with shrinking countdown halos (+500 points & full boost tank).
- **Juice & Game Feel**: Screen micro-shakes, expanding shockwaves, bouncing floating damage text (`+100`, `+500 NOVA!`, `COMBO x3!`), and exploding spark embers.
- **5 Aesthetic Cyberpunk Palettes**: Cyber Neon, Synthwave Sunset, Emerald Matrix, Solar Flare, and Royal Amethyst.
- **Wall Boundary Modes**: Toggle between `SOLID` (classic collision) and `PORTAL` (wrap-around torus).
- **Retro CRT Filter**: Toggleable curved vignette and arcade scanlines.
- **100% Mobile & Touch Friendly**: Touch swipe gestures + on-screen cyber D-pad and boost button.

## 🚀 Quick Start

No build steps, no package managers, no server needed.

1. Clone or download this repository.
2. Double-click `index.html` to play in any modern web browser.
